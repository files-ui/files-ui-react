# useFilesUI Headless Hook Demo

Next.js 16 App Router demo showcasing the **headless architecture** of `@files-ui/react` v2.0.

## 🎯 What This Demonstrates

- **✅ Full UI Control**: No default styles, build any design with Tailwind CSS
- **✅ Server Actions**: Native Next.js 16 App Router integration  
- **✅ Drag & Drop**: Complete drag-and-drop support
- **✅ Custom Validation**: File type, size, and count validation
- **✅ TypeScript**: Full type safety

## 🚀 Running the Demo

`ash
npm run dev
`

Navigate to http://localhost:3000
